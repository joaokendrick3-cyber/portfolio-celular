# Portfólio (celular)

App instalável (PWA) do Portfólio para iPhone, só leitura. O computador monta o resumo (`Portfólio/app/celular.py`) e envia ao Supabase; este app só mostra.

- `npm run dev`: desenvolvimento com `dev/resumo-real.json` (cópia local, fora do git).
- `bash publicar.sh "mensagem"`: compila e publica no GitHub Pages (branch gh-pages).
- Nunca versionar dados reais nem chaves.
